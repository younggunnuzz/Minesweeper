# Minesweeper
The console game Minesweeper.

# Рівні складності
- 0 — Вихід
- 1 — Легкий: поле 5x5, 3 міни
- 2 — Середній: поле 8x8, 8 мін
- 3 — Складний: поле 10x10, 15 мін

# Позначення
- . — закрита клітинка
- F — прапорець
- пробіл — порожня відкрита клітинка
- 1-8 — кількість мін навколо
- * — міна

# Керування
Введення через пробіл: "дія" "стовпець" "рядок"
- o A 1 — відкрити клітинку A1
- f A 1 — поставити або зняти прапорець на A1
- 0 0 0 — вихід у меню

Перший хід завжди безпечний.

# Умови закінчення гри
- Win: всі міни закриті прапорцями або всі безпечні клітинки відкриті.
- Lose: спроба відкрити клітинку з міною.
